# Security Policy

## Supported versions

Only the latest `0.x` line is supported during the pre-1.0 phase.

## Reporting a vulnerability

Please do not open public issues for security reports.

Email the maintainer or open a private GitHub security advisory once the remote repository is live. Include:

- impact summary
- affected files or commands
- reproduction steps
- suggested fix if available

We will acknowledge valid reports as quickly as possible and coordinate a fix before public disclosure.
