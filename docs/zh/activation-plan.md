# Activation Plan

[English](../activation-plan.md) | [简体中文](activation-plan.md)

这份文档是仓库级 activation 摘要，目标是在不扩新功能的前提下，把公开入口、试用路径和 GitHub-native adoption 面打通。

核心判断：
- canonical home = GitHub repo README
- GitHub Pages = 公开 proof surface
- Releases = 第二入口
- GitHub Action = adoption 面，而不是第一入口

当前主线优先级：
1. discover
2. understand
3. trust
4. try
5. activate

详细工作蓝图与历史背景请继续查看英文原文 [../activation-plan.md](../activation-plan.md) 和 `trans.md`。
