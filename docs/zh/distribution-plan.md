# Distribution Plan

[English](../distribution-plan.md) | [简体中文](distribution-plan.md)

AnswerLens 的分发不是单一渠道，而是一条 GitHub-native 分发链：

- README：canonical home
- Pages：公开 proof surface
- Releases：第二入口
- Starter bundle：外部 adopter 的复制资产
- GitHub Action：团队 adoption 面

这份计划的重点不是“铺更多渠道”，而是让这些面之间讲同一套 first-run funnel。

更完整的阶段拆分、指标与运营约束请查看 [../distribution-plan.md](../distribution-plan.md)。
