# AEO vs GEO vs AI Visibility

The naming around AI-mediated search is still unsettled. AnswerLens uses these terms carefully so the project stays understandable without leaning on hype.

## AEO

Answer Engine Optimization usually means improving how content appears in answer-style experiences. It is useful shorthand, but it can drift toward vague marketing if not tied to measurable evidence.

## GEO

Generative Engine Optimization usually means optimizing for retrieval and synthesis by generative systems. It is broader than classic SEO, but the field is still young and definitions vary.

## AI visibility

AnswerLens uses AI visibility as the practical umbrella: can an AI system discover, understand, cite, compare, and recommend the product based on available source material?

## Why AnswerLens says "CI for AI discoverability"

The phrase keeps the project anchored in engineering behavior:

- run checks before or during release
- inspect versioned artifacts
- fix source-material gaps
- compare before/after evidence
- avoid ranking guarantees
