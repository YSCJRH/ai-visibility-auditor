# Limitations

AnswerLens is intentionally constrained.

- It does not scrape consumer AI UIs.
- It does not guarantee placement on any AI platform.
- It does not replace product analytics or Search Console.
- It only targets product websites and docs-heavy sites in the current phase.
- `eval` currently ships with OpenAI and Perplexity adapters plus normalized manual imports.
- The bundled prompt pack is a practical benchmark pack with holdouts, not the full long-term research taxonomy.
- `before-after-diff.md` compares against the previous `eval-results.json` in the same output directory.
