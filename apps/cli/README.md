# AnswerLens CLI

`@answerlens/cli` is the publish-ready package for AnswerLens.

AnswerLens is a CLI-first AI visibility auditor for product websites.

Core behaviors:

- `audit` checks whether a site can be read, cited, compared, and recommended by AI systems
- `eval` benchmarks prompt packs with live providers
- `manual-import` scores normalized answer samples without scraping consumer AI UIs
- `search-console-import` validates audit coverage against imported page-level Search Console exports

The repository slug is `ai-visibility-auditor`; the public product name is `AnswerLens`.

See the main repository README for the full output contract, sample artifacts, and non-goals.
